# Worldmap Blips (WordPress Plugin)

Плагин добавляет интерактивную карту с метками (blips), всплывающими карточками и локальными ассетами.

## 1) Установка и запуск

1. Скопируйте папку `world-map` в `wp-content/plugins/world-map`.
2. Активируйте **Worldmap Blips** в админке WordPress.
3. Добавьте карту на страницу через shortcode или Gutenberg-блок.

## 2) Shortcode и совместимость

### Канонический shortcode (основной)

Используйте в контенте:

```text
[world_map]
```

PHP-вставка в шаблон:

```php
<?php echo do_shortcode('[world_map]'); ?>
```

### Backward compatibility alias (deprecated)

Старый shortcode поддерживается только для обратной совместимости:

```text
[worldmap_blips]
```

> `[worldmap_blips]` помечен как **deprecated**. Для новых страниц используйте только `[world_map]`.

## 3) Оффлайн-режим и локальные ассеты

Плагин ориентирован на локальную работу без внешних картографических CDN.

### Что используется локально

- Локальная SVG-карта: `world-map/assets/maps/world.svg`.
- Локальные JS/CSS ассеты плагина: `world-map/assets/js/*`, `world-map/assets/css/*`.
- Данные маркеров загружаются из WordPress (БД/REST этого же сайта).

### Ограничения оффлайн-режима

- Фоновые «тайлы» будут работать только если локально подготовлены файлы в `assets/maps/tiles/{z}/{x}/{y}.webp`.
- Без подготовленных локальных тайлов карта всё равно рендерится, но без дополнительного тайлового слоя.
- Плагин не выполняет обязательных запросов к внешним API/сервисам для базового рендера карты.

## 4) Ограничения и эксплуатационные заметки

- Плагин зависит от корректной работы WordPress REST API на вашем сайте.
- При жёстких правилах CSP убедитесь, что разрешены локальные скрипты/стили текущего домена.
- Для production рекомендуется включить стандартные механизмы кеширования WordPress.

## 5) Acceptance checklist (по ТЗ)

Ниже — чеклист приемки, включая ключевой критерий **no external requests**.

### A. Канонический shortcode
- [ ] В README везде основным указан `[world_map]`.
- [ ] В UI/подсказках админки основным указан `[world_map]`.
- [ ] `[worldmap_blips]` явно отмечен как deprecated alias.

### B. Рендер и функциональность
- [ ] Страница с `[world_map]` корректно рендерит карту.
- [ ] Маркеры отображаются в ожидаемых координатах.
- [ ] Попапы открываются без JS/PHP ошибок.

### C. Оффлайн и локальные ресурсы
- [ ] В DevTools Network нет запросов к внешним доменам при открытии страницы с картой.
- [ ] Загружаются только ассеты текущего сайта (same-origin).
- [ ] Карта работает при отключённом интернете (при доступности локального сайта).

### D. No external requests (обязательный критерий)
- [ ] Проверено, что плагин не требует внешних CDN/API для базовой работы.
- [ ] Любые данные карты/маркеров приходят только из локального WordPress.
- [ ] Нет `http(s)` запросов к сторонним доменам в коде плагина и во время рантайма страницы карты.

## 6) Быстрый smoke-test

1. Создать/открыть страницу с `[world_map]`.
2. Открыть страницу на фронтенде и убедиться, что карта рендерится.
3. Проверить Network: только same-origin запросы.
4. Временно отключить интернет/внешний доступ — убедиться, что карта продолжает работать на локальных ассетах.
5. Проверить, что старые страницы с `[worldmap_blips]` продолжают работать (deprecated alias).
